From Feature Lists to Enforced Invariants: AgentGov-Bench, a Deployability Benchmark for Multi-Agent LLM Orchestration Platforms

Pujitha Sri Lakshmi Paladugu
Independent Researcher · ORCID 0009-0001-5678-4022

Preprint · 2026-10-11 · 10 pages · Full text (PDF)

Abstract

Context: Multi-agent systems built on large language models now plan, call tools and execute code in production settings. Benchmarks measure what such agents can do, and separate efforts measure robustness to prompt injection, but no standard measures whether the orchestration platform that runs them is deployable: whether it terminates, behaves consistently, recovers from faults and enforces governance controls. Objective: We propose AgentGov-Bench, a benchmark that scores a deployed multi-agent platform on four separately reported axes (capability, reliability, governance and cost) and treats governance as eight behavioural invariants to be tested, not as features to be listed. Method: We define the invariants, a test procedure and pass criterion for each, a reliability protocol and a non-fungible deployability profile, and a reference architecture whose components map one-to-one to the invariants. As preliminary evidence we audited the official documentation of five widely used open-source frameworks against the invariants. Results: All five document bounded termination and human-in-the-loop approval as built-in features. None documents per-agent identity as a built-in feature; three offer it through an integration or hosted service. Built-in sandboxed code execution is documented by one framework. The documentation also records conditions under which controls fail open or do not cover all tool types. Conclusion: Feature availability does not establish enforcement. Deployability must be measured on the configured system with behavioural tests, which AgentGov-Bench specifies.

Keywords: LLM agents; multi-agent systems; benchmark; AI governance; reliability; prompt injection; software architecture
